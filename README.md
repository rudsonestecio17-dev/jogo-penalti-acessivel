# ⚽ Jogo de Pênalti Acessível (Single-Switch Game)

Um jogo de futebol acessível desenvolvido em HTML5 e JavaScript para pessoas com paralisia cerebral ou limitações motoras. O projeto utiliza a mecânica de **acionador único (single-switch)**, permitindo jogar com apenas uma tecla, toque na tela ou botão assistivo.

---

## 🚀 Como Jogar

Você pode jogar diretamente no seu navegador acessando o link público do GitHub Pages:
👉 **[Clique aqui para abrir o jogo](https://seu-usuario.github.io/nome-do-repositorio/)**

### Controles
- **Qualquer Tecla (`Espaço`, `Enter`):** Aciona o chute.
- **Clique / Toque na Tela:** Funciona como botão gigante para acionamento por toque.

---

## ♿ Recursos de Acessibilidade
- **Mecânica de Botão Único:** Compatível com acionadores de pressão, piscada de olhos e chaves assistivas USB.
- **Velocímetro Ajustável:** Opção no menu para alterar a velocidade do ponteiro (*Muito Lenta, Média, Rápida*).
- **Elementos de Alto Contraste:** Trave destacada, bola amarelo-canário e ponteiro laranja neon.
- **Feedback Multissensorial:** Efeitos sonoros para chute e defesa, além de sintetizador de voz com grito de *"Gooool!"*.

---

## 🛠️ Tecnologias Utilizadas
- **HTML5 Canvas 2D:** Renderização dos gráficos e animações.
- **JavaScript (ES6+):** Lógica do jogo e eventos universais de entrada.
- **Web Audio API & Web Speech API:** Geração sintética de áudio e síntese de voz.
